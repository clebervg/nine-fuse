# Bloco 9, Super 9 e Cascade Budget Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Substituir a explosão do dígito máximo por dois efeitos novos e
determinísticos — Bloco 9 (limpa bloqueadores 3x3, sem cascata própria) e
Super 9 (conversão passiva de todo um valor no tabuleiro) — e formalizar o
teto de cascatas do turno como `CascadeBudget`, mantendo a UI e a economia
do jogo compilando e coerentes.

**Architecture:** Todo o contrato novo vive no `MatchEngine` (motor puro,
sem Flutter). `Tile` ganha os campos de peça especial já desenhados no spec
de ontem, reaproveitados aqui para o Super 9. Os notifiers (`GameNotifier`,
`EndlessNotifier`) e a `JuiceOverlay` são atualizados para consumir o novo
contrato sem duplicar regra. Um `JuiceDirector` novo, puro, decide qual
evento de apresentação vale a pena mostrar numa jogada.

**Tech Stack:** Dart puro (domínio), Flutter (`AnimationController` para
qualquer animação nova, nunca `Future.delayed` em widget), Riverpod
(`StateNotifier`), `flutter_test`.

## Global Constraints

- Nenhum `Future.delayed` em widget de UI — animações usam
  `AnimationController` (regra do projeto, `CLAUDE.md`).
- Toda animação nova é finita (nunca `repeat()`), senão `pumpAndSettle`
  trava a suíte de widget.
- `Opacity`/`FadeTransition` são marcadores usados por outros testes
  (obstáculos, transições de rota) — nenhum efeito novo deve usá-los;
  translucidez é alfa de cor.
- Peça especial só nasce por `Tile.withSpecial` — nunca por `copyWith` com
  `specialType`/`specialTurnsLeft` soltos (mantém o invariante do `assert`).
- `_maxCascades = 64` continua existindo, só como rede de segurança contra
  loop infinito — não é o limite prático depois deste plano.
- `kMaxCascadesPerTurn`/`CascadeBudget` vale **4**, não mais 5 (spec de
  ontem previa 5; este pedido ajustou o número).
- `dart run tool/simulate_economy.dart` precisa continuar compilando e
  rodando ao final do plano — é a rede de segurança da economia do jogo.

class CascadeBudget {

```dart
import 'package:nine_fuse/features/game/domain/match_engine.dart';
import 'package:nine_fuse/features/game/presentation/juice/juice_priority.dart';

/// Decide qual evento de apresentação uma jogada merece, sem conhecer
/// widget nem `AnimationController`. Regra de sobrescrita: supernova
/// suprime qualquer outro evento da mesma jogada — quem consome o
/// resultado (a UI) não precisa aplicar essa regra de novo, só ler o
/// valor mais alto encontrado.
class JuiceDirector {
  const JuiceDirector._();

  static JuicePriority priorityOf(Resolution resolution) {
    var best = JuicePriority.normal;

    for (final step in resolution.steps) {
      for (final fusion in step.fusions) {
        final priority = _priorityOfFusion(fusion);
        if (priority.index > best.index) best = priority;
      }
    }

    return best;
  }

  static JuicePriority _priorityOfFusion(FusionEvent fusion) {
    if (fusion.specialType != null) return JuicePriority.supernova;
    if (fusion.matchLength >= kBigMatch) {
      return fusion.value == kMaxDigit ? JuicePriority.epic : JuicePriority.great;
    }
    return JuicePriority.good;
  }

  /// A ativação do Super 9 (troca que dispara a conversão board-wide) não
  /// passa por `Resolution` — é seu próprio `MoveResult`. Sempre o topo da
  /// hierarquia.
  static JuicePriority priorityForSuperNineActivation() => JuicePriority.supernova;
}
```
